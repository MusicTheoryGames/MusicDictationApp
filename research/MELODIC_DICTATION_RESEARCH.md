# Melodic Dictation: Why Students Struggle, What Helps, What to Build

Deep research report (2026-07-02), five parallel search agents cross-corroborated.
Companion to MELODIC_LADDER_EXPANSION_PLAN.md (which maps these findings onto the
M0–M26 ladder) and INTERVAL_TRAINING_RESEARCH.md. Confidence flags: **[strong]** =
multiple independent peer-reviewed sources; **[moderate]** = one good study or
practitioner consensus; **[contested]** = literature disagrees; **[gap]** =
plausible but untested.

Headline: the intuitive "help the student" moves — forcing sing-back before
writing, and live attention-directing prompts during a test — are empirically
COUNTERPRODUCTIVE. Build them as training on short material, never as mandatory
mid-dictation steps.

## 1. Documented pain points
1.1 **Working-memory overflow — the dominant failure. [strong]** Auditory WM holds
~3–4 chunks (Cowan); memory for unfamiliar melodies collapses past ~10 notes
(Pembrook 1986, JRME 34:238–261, avg accuracy 48%). Tonal WM predicts dictation
(Nichols & Springer 2025, β=.406). https://journals.sagepub.com/doi/10.2307/3345259 ·
https://pmc.ncbi.nlm.nih.gov/articles/PMC12341474/ ·
https://digitalcollections.lipscomb.edu/cgi/viewcontent.cgi?article=1190&context=jmtp
1.2 **Can't chunk — note-by-note storage. [strong]** Expertise = recoding 14 notes
into 4–5 units; span is ~16 for tonal vs ~8 for random sequences (structure, not
capacity, is trained). Karpinski 1990 JMTP 4; PLOS ONE 2018.
https://digitalcollections.lipscomb.edu/jmtp/vol4/iss1/10/ ·
https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0201765
1.3 **Losing the tonic mid-melody. [moderate]** Worsens with accidentals/minor;
mechanism under-specified. Student reports + Karpinski model.
1.4 **Simultaneous rhythm+pitch load. [strong]** Single attentional stream; pitch is
the weaker channel (rhythm M=21.7 vs pitch M=14.65, N&S 2025); rhythm-first helps
rhythm at no pitch cost (Beckett 1997). https://mtosmt.org/issues/mto.21.27.2/mto.21.27.2.chenette.html ·
https://doi.org/10.2307/3345426
1.5 **No protonotation → "guessing wildly." [moderate]** Time pressure tempts leaping
to staff. https://uen.pressbooks.pub/auralskills/chapter/understanding-the-process-of-dictation-step-by-step/
1.6 **Write-while vs write-after. [contested]** Karpinski/Rogers say wait; Buonviri
2017/2021 found NO significant difference and no benefit forcing non-preferred
strategy. https://eric.ed.gov/?id=EJ1155293 · https://journals.sagepub.com/doi/10.1177/0022429420946308
1.7 **Contour vs exact-degree confusion. [strong]** Separate memory codes (Dowling
1978); interval-ID explains ~29% variance (N&S 2022).
https://journals.sagepub.com/doi/10.1177/00224294211011962
1.8 **Leaps/weak-degree landings. [moderate]** Errors cluster within a M2, big
intervals under-estimated ("contraction," Ortmann 1933).
1.9 **Minor + chromaticism. [moderate]** Fixed-do gives no accidental syllable; note
density is the biggest difficulty knob (Baker η²=.46). https://davidjohnbaker1.github.io/document/experiment.html
1.10 **Modulation disorientation. [moderate]** 1.3 at phrase scale.
1.11 **Notational fluency / speed. [moderate]** Karpinski's 4th-stage failure.
1.12 **Test anxiety under limited hearings. [gap]** Vivid anecdotes, no peer-reviewed
measure — a real research gap.
1.13 **Transfer gap (app-specific). [moderate]** Drill success ≠ transcription; unlimited
replays let students brute-force. https://www.earmaster.com/forum/viewtopic.php?t=5463
Diagnostic meta-point **[strong]:** a wrong transcription can't reveal WHICH stage
failed (Klonoski 2006 MEJ). https://eric.ed.gov/?id=EJ755079

## 2. Evidence-backed remedies (condensed)
2.1 Karpinski 4-stage model (hear → memory → understand → notate) as the training
skeleton — but not as live test prompts. 2.2 Protonotation (beat slashes + contour
arrows + degree numbers); onset-marking shorthand (Brown 2020 JMTP 34). 2.3
Extractive listening / directed attention as a TRAINED routine (Beckett) — NOT live
(Paney 2016 lowered scores). 2.4 **Sing-back before writing mostly HARMFUL — do not
mandate** (Pembrook, Buonviri, Lima; inaccurate singing overwrites memory). 2.5
Scale-degree function first (Buonviri & Paney 2015, 398 teachers). 2.6
Memory-before-notation drills (deliberately overflow memory to force extraction).
2.7 Chunk training on frequency-common patterns (Gordon/Kodály banks; IDyOM
ranking); generic span training does NOT transfer (Melby-Lervåg 2016, 87 studies).
2.8 Task-per-hearing + budget P=(Ch/L)+1; Chenette MKMAN. 2.9 Bookend anchoring
(Paney & Buonviri 2014). 2.10 Error-classification feedback (unmet need). 2.11
Cadence/bass-line as standalone skill (Chenette 2021; 88% used bass). 2.12
Interleaving > blocking for interval learning (Wong/Chen/Lim 2021); retrieval
practice; statistical learning builds expectation schemata.

## 3. Micro-skill ladder no product ships end-to-end
Scale-degree-after-cadence loop → frequency-ranked chunk echo → growing-span tonal
memory → protonotation entry → short-span sing-back CHECK only → hearing-budget with
per-hearing task → bookend anchoring → cadence recognition → next-note prediction
**[gap]** → stage-isolated error feedback. Difficulty dials: length/chunk count,
note density (η²=.46), tonalness→minor→chromatic, interval size, IDyOM surprisal,
multi-timbre.

## 4. Top 8 buildable interventions, ranked
1. Scale-degree-function first **[strongest]** — already the app's design.
2. Domain-specific tonal chunk-vocabulary drills **[strong]**.
3. Growing-span tonal memory game feeding dictation **[strong]**.
4. Evidence-based difficulty engine (density/length/tonalness/interval/surprisal) **[strong]**.
5. Stage-isolated practice + error-classification feedback **[strong need, moderate direct evidence]**.
6. Hearing-budget with task-per-hearing, trained not live-prompted **[moderate]**.
7. Protonotation entry + bookend anchoring **[moderate]**.
8. Cadence/bass-line track **[moderate]**.

DO NOT build as mandatory: forced sing-back before full-melody writing; live
attention prompts during graded rounds; hard-forced writing timing; unlimited
replays as default.

Open research gaps to instrument: next-note prediction as a dictation intervention;
dictation anxiety under limited hearings; whether a protonotation/error-feedback UI
actually improves outcomes.
